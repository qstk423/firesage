# 演示截图拍摄说明（申报用）

按 `docs/解决方案-消安智答FireSage.md` 第四节清单拍摄。本地先启动：

```bash
cd backend && python3 main.py
# http://127.0.0.1:8319
```

## 拍摄前

1. 浏览器最大化，缩放 100%。  
2. 强制刷新（Cmd+Shift+R），避免旧前端缓存。  
3. 勿露出个人桌面、其他聊天窗口。  
4. 截图保存到 `docs/screenshots/`（可自建目录，勿提交隐私信息）。

## 必拍 6 张（时间紧时的最小集）

| 文件 | 内容 |
|------|------|
| `02-口语法规问答.png` | 「楼道堆放杂物违反什么规定」完整回答（含顶栏风险） |
| `03-条款溯源.png` | 支撑条款 + 官方链接 |
| `04-应急分流.png` | 「家里着火了现在怎么办」 |
| `06-图谱总览.png` | 分簇漂浮总览 |
| `07-图谱一级二级连线.png` | 点选后实线/虚线 |
| `10-意图微调对比.png` | `python3 backend/scripts/train_intent.py --compare` 终端输出 |

## 本版新增（建议补拍）

```bash
python3 backend/scripts/train_intent.py --compare
python3 backend/scripts/evaluate_fireeval.py --split dev
```

把终端完整指标框进截图即可。
