## 一、3 分钟演示脚本（必背）

**开场 15 秒**  
「消安智答面向消防法规咨询与火灾应急提示。原则是：法规事实来自检索，证据不足就拒答；真火情先走 119。」

| 顺序 | 时长 | 操作 | 口述要点 | 镜头要露什么 |
|------|------|------|----------|--------------|
| 1 | 50s | 首页点「楼道堆放杂物违反什么规定」 | 口语进法规；结论+依据+风险置顶；下方相关追问 | 回答卡片顶栏风险、条款、4 个玻璃追问框 |
| 2 | 25s | 点一个追问（如「怎么处罚」） | 多轮上下文；不必重打长句 | 追问理解提示 + 新答案 |
| 3 | 40s | 点「在知识图谱中查看证据链」→ 点邻居切换中心 | GraphRAG 不是装饰；点选切换有动画 | 局部子图、实线一级/虚线二级、球位切换 |
| 4 | 30s | 新问「家里着火了现在怎么办」 | 应急分流，不查罚则 | 119 指引全文，无乱套条款 |
| 5 | 20s | 新问「网络安全法怎么规定」或「消防知识」 | 库外拒答 / 问太宽引导 | 拒答或引导话术（含「可以问/例如」） |
| 收 | 10s | 切回问答页 | 「可评测、可核验、可演示」 | 仓库/FireEval 一句话 |

**备用问（翻车时用）**  
- 占用消防通道怎么处罚  
- 电动车能不能在楼道充电  
- 消防控制室可以没人值班吗  
- 发现火灾隐患怎么办（应走法规/整改，**不是** 119 应急；可对照「家里着火了」）  

**现场禁忌**  
- 不要刷新首页指望「换题」——首页四题固定，方便复现  
- 不要临场编新问；图谱动画已锁定，勿再改布局

## 三、PPT 建议目录（10–12 页）

1. **封面**：消安智答 · 大模型微调与 RAG 融合的智慧消防问答  
2. **痛点**：口语难查、误答代价高、应急与咨询易混  
3. **目标用户**：物业/网格员/值班员 + 赛道命题对齐  
4. **总体架构**（整页图）：见第四节  
5. **核心能力 1**：混合检索 + 引用核验 + 拒答/引导  
6. **核心能力 2**：GraphRAG 证据链（一级实线 / 二级虚线）  
7. **核心能力 3**：意图微调 + 风险等级 + 相关追问  
8. **评测与消融**：FireEval + 检索消融表（Hit@1：BM25 0.61 → full 0.90）  
9. **演示回放**：三问截图拼页  
10. **边界与规划**：免责声明；双模式（快速问答/深度溯源）等下一步  
11. **分工与仓库**：成员 + GitHub 链接  
12. **致谢 / Q&A**

每页原则：**一个标题 + 一张主图/一表 + ≤3 条子弹**，勿贴大段代码。

## 五、计划书 vs PPT vs 视频 怎么分工

| 材料 | 写什么 | 别写什么 |
|------|--------|----------|
| 计划书 | 背景、方案、指标、分工、进度、风险 | 不要贴全部 UI 细节 |
| PPT | 痛点→架构→三亮点→评测→演示 | 不要超过 12 页正文 |
| 视频 | 按脚本三问必杀 | 不要超过 3 分钟 |

计划书若已有 PDF，本包只补「答辩话术与演示」；技术方案以 `docs/解决方案-消安智答FireSage.md` 为准。

### 讲述顺序
1. 痛点 30s → 2. 架构 40s → 3. 现场三问 2.5min → 4. 消融数字 30s → 5. 边界 15s  

### 可能被问到的点（短答）
- **和 ChatGPT 区别？** 检索与生成解耦，有核验与拒答，不靠模型背条文。  
- **图谱有什么用？** 回答可跳局部证据链，实体关系可点选展开，支撑溯源叙事。  
- **微调做了什么？** 意图路由领域微调（可展示 compare 终端）；生成 LoRA 为迭代项。  
- **指标？** 检索消融 full Hit@1≈0.90；FireEval 约 229 题（含物业高频）。
