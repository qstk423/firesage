- **和 ChatGPT 区别？** 检索与生成解耦；有核验与拒答；真火情先走 119。  
- **微调做了什么？** 意图路由领域微调（可展示 compare）；生成 LoRA 是迭代项，不是演示前提。

- **能不能全国上线？** 当前是可评测样板 + 试点能力；正式产品还需账号治理与运维（诚实边界）。
