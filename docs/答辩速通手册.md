## 一、一分钟项目是什么

消安智答 = **智慧消防场景下的可信问答**：基层用口语问，系统先分清「咨询 / 着火 / 拒答」，再检索法规作答，并给出处；答不了就承认，不编造条款。

对齐讯飞命题三点：
1. **大模型微调**（意图路由已落地）
2. **RAG 融合**（关键词 + 向量 + 图谱）
3. **智慧消防应急问答**（咨询与 119 分流）

## 二、系统每一段在干什么（按一次提问走）

把它想成流水线，评委问「流程」就按这个说：

| 步骤 | 干什么 | 你怎么讲 |
|------|--------|----------|
| ① 意图路由 | 判断：法规咨询 / 真火情 / 拒答引导 / 闲聊 | 「先分对路，分错比答丑更危险」 |
| ② 场景结构化 | 抽出主体、行为、场所等，口语改写成可检索问法 | 「把大白话变成能搜的查询」 |
| ③ 三路召回 | BM25（关键词）+ 向量（语义）+ GraphRAG（关系） | 「法言靠关键词，口语靠向量，关系靠图谱」 |
| ④ 融合精排 | RRF 融合 + 法规意图重排 + CrossEncoder | 「多路结果合成并排序，提高条款命中」 |
| ⑤ 约束生成 | 只根据检索到的条款组织答案 | 「不靠模型背条文」 |
| ⑥ 引用核验 | 引用是否在依据内；不够就降级/拒答 | 「核不过就不硬答」 |

前端你还会看到的「体验层」（不是检索本身，但是加分点）：
- **风险置顶**：紧急/高/中/低
- **相关追问**：气泡外 3–4 条
- **拒答 vs 引导**：库外拒答；问太宽先给示例
- **图谱证据链**：从回答跳子图，点邻居换中心

## 五、微调知识（答辩高频，必须会）

### 5.1 我们说的「微调」到底微调了什么？

不是「把整本消防法背进大模型」。分三层，你要能分开讲：

| 层级 | 状态 | 作用 | 答辩怎么说 |
|------|------|------|------------|
| **意图路由微调** | ✅ 已完成并上线 | 决定走哪条业务路径 | 「优先做，因为分错路径最危险」 |
| **条款重排微调** | ✅ 有模型与开关，默认常关 | 帮精排更准 | 「实验做过，需要时可开」 |
| **生成式 SFT / LoRA** | ✅ 数据已备；权重训练待 GPU/云端 | 让生成更贴结构化答案 | 「数据就绪，线上仍是检索约束生成 + 降级」 |

线上默认意图策略：**hybrid = 规则 + 微调混合**（比单用规则或单用模型更稳）。

### 5.2 意图微调：数字怎么念

对比结果（`intent_compare.json`，记住 test 那一行）：

| 划分 | n | 规则 | 纯微调 | **混合 hybrid** |
|------|---|------|--------|-----------------|
| dev | 29 | 1.0 | 0.9655 | **1.0** |
| test | 32 | 0.9062 | 0.9375 | **0.9688** |

你对外说：  
「测试集上混合路由准确率 **0.9688**，高于单独规则或单独微调。」

意图类别（大致）：法规咨询 `law`、应急 `emergency`、拒答 `refuse`、闲聊 `chitchat`。

### 5.3 为什么先微调「意图」而不是先微调「生成」？

标准答法：  
「消防场景里，把真火情错分去搜罚则，或把库外问题硬答成假条款，危害更大。所以先把分流做稳、做可测；生成侧用检索约束 + 核验拒答托底，SFT/LoRA 作为下一阶段增强。」

### 5.4 RAG 消融（证明检索不是玄学）

| 模式 | 含义 | Hit@1（约） |
|------|------|-------------|
| bm25 | 仅关键词 | 0.61 |
| bm25_vector | +语义向量 | 0.73 |
| hybrid | 三路但无重排 | 0.57（图谱要重排托住） |
| **full** | 三路 + 重排 + CE | **≈0.90** |

讲法：  
「加向量明显提升；图谱要配合重排；完整链路首位命中约 0.90。」

### 5.5 评委刁难题速答

- **微调做了吗？** 做了，意图路由已上线可复现；重排有实验；生成 SFT 数据已备。  
- **和 ChatGPT 有啥区别？** 我们不背条文；有分流、检索、核验、拒答；可评测。  
- **图谱干什么？** 第三路召回 + 回答后可解释证据链。  
- **会不会胡说？** 核验失败降级；不够就拒答；火情不进罚则。  
- **知识库多大？** 10 部来源，约 524 条款（以现网为准）。  
- **商业化了吗？** 创意计划原型；先验证可信，再试点订阅/对接。

## 六、现场演示建议（若被要求点开系统）

准备三问即可：
1. 法规：「楼道堆放杂物违反什么规定」→ 看结论、依据、风险、追问  
2. 应急：「家里着火了现在怎么办」→ 必须是 119 指引，不是罚则  
3. 边界：「今天天气怎么样」或明显库外 → 拒答/引导  

再点一下图谱/证据链，说「出处可核对」。
