# 消安智答 · 部署与配置清单

> 版本 v0.8.2 · 试点最小运维页  
> 本地演示：`cd backend && python3 main.py` → http://localhost:8319  
> Docker：`docker compose up --build -d`  
> 答辩预检：`python3 backend/scripts/demo_check.py --preflight`（见 `docs/答辩前检查清单.md`）

---

## 1. 必选 / 可选环境变量

| 变量 | 默认 | 说明 |
|------|------|------|
| `LLM_BASE_URL` | 空 | OpenAI 兼容接口；空则抽取式回答 |
| `LLM_API_KEY` | 空 | 大模型密钥（勿提交 Git） |
| `LLM_MODEL` | 空 | 如 `deepseek-v4-flash` |
| `API_KEY` | 空 | 设置后 `/api/*`（除公开接口）需 `X-API-Key` |
| `RATE_LIMIT_PER_MIN` | `60` | 每 IP 每分钟上限；`0` 关闭 |
| `FIRESAGE_LITE` | 空 / compose=`1` | `1`=跳过 bge，TF-IDF 降级，启动快 |
| `USE_HF_MIRROR` | `1` | 走 hf-mirror |
| `HF_ENDPOINT` | 镜像地址 | 可覆盖 |
| `AUDIT_DIR` | `backend/data/audit` | 问答审计目录 |
| `AUDIT_DISABLED` | 空 | `1`=关闭审计与反馈落盘 |
| `INTENT_BACKEND` | 自动 hybrid | `rules` / `ml` / `hybrid` |
| `RERANK_ML` | 关 | `1`=开启重排微调模型 |

本地密钥：复制 `backend/.env.example` → `backend/.env.local`（仅 `LLM_*` 由客户端自动加载）。

## 4. Docker 提示

### 轻量演示（默认）
```bash
docker compose up --build -d
```
- `FIRESAGE_LITE=1`：BM25 + TF-IDF + 图谱，启动快。

### 全量质量档（B5）
```bash
# 先填写 backend/.env.local 中的 LLM_*
docker compose -f docker-compose.full.yml --env-file backend/.env.local up --build -d
# 本机也可自检
python3 backend/scripts/check_runtime.py
python3 backend/scripts/check_runtime.py --ping-llm --strict
```
- 含 torch / bge；首次构建与拉模型很慢。
- `/api/system` → `runtime.quality_tier` 应为 `full`；顶栏会显示「全量检索+生成」。

### 公网（B6）
1. 云主机安装 Docker，clone 后按上节启动（建议 full + 设置 `API_KEY`）。
2. 使用 [`nginx-firesage.conf.example`](nginx-firesage.conf.example) 反代 443。
3. 证书：Let's Encrypt 或云厂商证书。
4. 验收：`curl -s https://你的域名/api/system` 查看 `runtime`。
