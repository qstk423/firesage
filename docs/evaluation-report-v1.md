## 一、评测概述

### 1.1 评测目的

针对消安智答 FireSage 系统开展客观量化评测，验证其在消防法规问答场景下的
检索准确性、结论正确性、引用可信度与安全拒答能力，为产品迭代与交付提供依据。

### 1.2 评测范围

- 意图识别与路由准确性
- 多路检索（BM25 / 语义向量 / 知识图谱）排序质量
- 结论正确性与条款引用准确性
- 知识库外问题与应急问题的安全拒答
- 端到端响应性能

### 1.3 评测依据

| 依据 | 说明 |
|---|---|
| FireEval v1 评测集 | 204 题覆盖 8 类真实场景，含 22 道应拒答题、179 道必答结论题 |
| 发布门槛（v1） | Hit@1 ≥ 85%，Hit@3 ≥ 95%，引用准确率 ≥ 95%，拒答准确率 ≥ 95%，严重错误率 ≤ 1%，平均响应 ≤ 8s |
| 官方法规语料 | 消防法、61号令、高层民用建筑消防安全管理规定、消防安全责任制实施办法等，均含官方来源元数据 |

## 三、评测方法

### 3.1 评测集构成

| 类别 | 题数 | 考察能力 |
|---|---|---|
| 直接法规查询 | 44 | 条款检索与原文还原 |
| 生活化口语表达 | 40 | 口语到法规术语的语义映射 |
| 处罚与责任主体 | 35 | 主体—行为—处罚的图谱关联推理 |
| 跨条款综合问题 | 25 | 多条款整合与综合结论 |
| 多轮追问 | 20 | 上下文理解与追问衔接 |
| 应急问题 | 15 | 应急处置优先级（安全兜底） |
| 知识库外消防问题 | 15 | 越界识别与拒答 |
| 非消防问题 | 10 | 领域边界识别与拒答 |
| **合计** | **204** | 其中应拒答 22 题，含必答结论 179 题 |

### 3.2 指标定义

| 指标 | 定义 |
|---|---|
| 意图路由准确率 | 意图分类与预期一致的比例 |
| Hit@1 / Hit@3 | 预期条款出现在检索结果第 1 / 前 3 的比例 |
| MRR | 预期条款排名倒数的均值 |
| 结论正确率 | 必答结论全部命中的比例 |
| 引用准确率 | 引用条款与预期条款一致的比例 |
| 拒答准确率 | 应拒答题中正确拒答的比例 |
| 严重错误率 | 给出错误条款且用户可能据此采取危险行动的比例 |
| 平均响应时间 | 预热后单题端到端耗时均值 |

### 3.3 复现方式

```bash
cd backend
python3 scripts/evaluate_fireeval.py            # 完整 204 题
python3 scripts/evaluate_fireeval.py --strict   # 按发布门槛判定（CI 门禁）
```

评测在预热（模型加载与索引构建）后计时，排除首题加载干扰。
