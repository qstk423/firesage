# 消安智答 项目概述（科大讯飞企业命题·申报粘贴版）

> 厂商视角 + 技术要点（中文表述，无英文字母）；含产品、用户、愿景、竞品。

消安智答面向智慧消防应急场景，是一款融合大模型微调与检索增强生成的可信智能问答产品。用户以口语描述场景后，系统经意图路由完成法规咨询与火灾应急分流，再通过场景结构化与查询改写，开展关键词检索、语义向量检索与知识图谱检索三路召回，经多路融合与精排后，由大模型基于检索条款结构化作答，并经引用核验；证据不足或低置信时拒答，真火情则分流至一百一十九应急指引，避免编造条文。作品直接响应科大讯飞企业命题对微调与检索增强技术融合的要求。

面向用户以物业与单位消防安全管理人员、社区网格员与值班员为主，兼顾院校实训与基层合规培训，覆盖隐患咨询与突发火情提示等高频场景。

项目愿景是打造高风险垂直领域的可信问答样板：让消防法规变为可问、可核、可追溯的知识服务，形成领域微调、混合检索、图谱证据链与核验拒答相结合的可复现路径，降低误答带来的合规与安全风险。

相较通用对话大模型直接背条文作答，本项目坚持检索与生成解耦、引用核验与证据不足拒答；相较传统关键词检索与静态题库，本项目具备口语理解、三路混合检索、知识图谱一级二级证据链、风险等级提示、相关追问、应急与咨询安全分流，以及基于自建评测集的意图领域微调，更契合命题方可评测、可演示、可落地的要求。当前为创意计划阶段原型，知识库覆盖消防法、六十一号令等五百二十四条款（十部来源），图谱一百一十八实体、九百七十二关系，评测集含二百二十九题人工核验，输出仅供辅助参考，紧急情况请直接拨打一百一十九。
